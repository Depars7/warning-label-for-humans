A tiny program that writes one official-sounding, absurd safety warning label for every human being to /output/entry.txt, in a single line of 160 characters or fewer. The joke lands on a universal habit: reopening the fridge moments later, sincerely believing new food has spawned while no one was looking.

## Run it

```sh
python3 main.py
```
